# 포즈 시각 표현 재작업 · 2026-11-23

## 목표

사용자가 롤백한 강화안의 문제는 연결 서사보다 이미지·컴포넌트의 톤과 시각적 완성도였다. 기존 캐스트와 실제 앱 UI를 유지하며 선택 UI의 위계와 피드백을 정리한다.

## 구현

- 코랄 인원 타일, 2명에서만 노출하는 연분홍 관계 선택, 진한 빨강 추천 버튼.
- 선택·추천 상태를 안내하는 라이브 텍스트.
- 목록 갱신 타이머 취소, 랜덤 추천의 오래된 비동기 작업 취소.
- 새 이미지 추가 없음. CSS·main.js 캐시 버전 66.

## 검증

- npm run check 통과.
- npm test: DOM 대역을 통한 관계 표시, 연속 인원·관계 선택, 랜덤 추천 취소, 선택별 추천 이미지 확인 통과.
- git diff --check 통과.
- 브라우저 육안·모션·실기기 검수 미실행: Mac 잠금으로 CUA 사용 불가.
