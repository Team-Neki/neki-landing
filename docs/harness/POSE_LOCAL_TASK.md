### 네 컷 펼침 이후 관계별 연결 (2026-11-23 로컬 수정)

한 컷씩 강조하던 구간을 관계별 소개로 바꿨다. 네 컷이 펼쳐진 자리는 유지하고 친구→커플→썸 순서로 실제 해당 캐스트 사진 네 장이 교차 전환된다. 제목·설명·관계 밑줄 표시가 함께 바뀐다. 다음 관계 사진은 미리 HTML에 배치해 스크롤 전환 중 빈 이미지가 생기는 것을 줄인다.

마지막에는 썸 선택 상태로 이어지며, 이후 사용자가 고른 관계·랜덤 세트를 존중한다. 역스크롤하면 관계 순서도 되돌아간다. 동작 줄이기에서는 친구 기준의 최종 선택 상태를 제공한다. 자동 관계 상태·역방향·각 관계 에셋 경로 검사를 포함한 npm test 통과. 브라우저 시각 검수 미실행, 커밋·배포 없음.


## 스크린샷 중첩 수정

사용자 스크린샷에서 중앙 관계 제목과 오른쪽 기존 소개 문구가 겹쳤다. `.js .reveal.is-in`이 무대의 opacity 규칙보다 우선했던 것이 원인이다. 포즈 소개에서 generic reveal을 제거하고, 소개 fade-out(.01~.08)→관계 제목 fade-in(.10~.18), 관계 제목 fade-out(.80~.88)→최종 소개 fade-in(.90~.98)으로 분리했다. 사진은 실제 중앙 제목 영역 하단에 24~28px 여백을 두도록 계산한다. 관련 상태·좌표·reveal 재유입 검사를 추가했다. 실제 브라우저 검수는 미실행이다.


## 주요 장면 근처 정렬 · 로컬 작업안

`js/scene-scroll.js`를 추가했다. 휠·터치·스크롤 키 입력을 막지 않고, 마지막 스크롤 후 180ms가 지나면 현재 영역의 가까운 주요 장면으로만 180~300ms 동안 정렬한다. 최대 보정 거리는 180px 또는 화면 높이의 18% 중 작은 값이다. 같은 정지점에 반복해서 끌어당기지 않으며 새 입력·리사이즈·해시 이동·탭 숨김에 정렬을 취소한다. 실제 이동이 없거나 수평 휠·확대 입력이면 시작하지 않는다.

- 지도(데스크톱): 브랜드 모임 완료, 검색 결과, 매장 선택, 길찾기 완료. 모바일 지도는 시간 기반이므로 정렬 대상에서 제외한다.
- 포즈: 펼쳐진 친구(.43), 커플(.62), 썸(.78), 최종 직접 선택(.99).
- 아카이빙: 시작, 네컷 모임(.42), 앨범 카드(.67), 저장 완료(.99).
- 동작 줄이기에서는 정렬을 끈다. FAQ·일반 읽기 영역은 대상이 아니다.

동일한 구간의 빠른 스크롤은 중간 장면을 건너뛸 수 있다. 정렬 근처 밖에 멈추면 이동하지 않는다. npm test에 근접 정렬·건너뛰기·반복 끌림 방지·취소·읽기 영역·동작 줄이기 테스트를 포함했다. 코드 검사 통과, 실제 휠·트랙패드·모바일 감각 검수는 미실행. 로컬 미커밋·미배포 상태다.
